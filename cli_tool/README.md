# SQL Mastery CLI

An interactive CLI tool to practice writing queries directly against your local `school_management` database.

## Setup
1. Ensure your database is running (e.g., via `docker-compose up -d` from the project root).
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the CLI:
   ```bash
   python interactive_practice.py
   ```
